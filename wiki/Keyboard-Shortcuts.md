# Keyboard Shortcuts & Mouse Controls

## Global Hotkeys

| Shortcut | Mode | Behavior |
| :--- | :--- | :--- |
| `Alt + Tab` | Hold Mode | Targets previous (`2nd` most recent) window; each extra `Tab` steps deeper |
| `Alt + Shift + Tab` | Hold Mode | Targets oldest window; `Shift + Tab` steps shallower |
| Release `Alt` | Hold Mode | Commits selection (zero flash if released `< 90ms`) |
| `Alt + \`` or `Ctrl + Alt + Space` | Browse Toggle | Opens pinned Browse mode or closes if open |

## Overlay Navigation

| Key | Action |
| :--- | :--- |
| `Tab` / `Shift + Tab` | Step deeper / shallower (wraps) |
| `↓` / `↑` | Step deeper / shallower (clamps) |
| `PgDn` / `PgUp` | Step 5 windows deeper / shallower |
| `Home` / `End` | Jump to newest / oldest window |
| `→` / `←` | Jump to next / previous Virtual Desktop |
| `1`–`9` *(empty filter)* | Jump to Virtual Desktop `1`–`9` |
| `Space` *(Hold mode, empty filter)* | Pin Hold mode into Browse mode |
| `Enter` | Focus selected window and close |
| `Esc` | Clear filter, or cancel and close |

## Mouse, Sounding Line & Drag-and-Drop

| Gesture | Target | Action |
| :--- | :--- | :--- |
| **Click** | Window card / caption / minimap tile | Focus window and close |
| **Click** | Empty Virtual Desktop card | Switch directly to that Virtual Desktop |
| **Click** | `+ New desktop` card | Create new Windows Virtual Desktop on-page |
| **Drag & Drop** *(`>= 6px`)* | Card or tile → Desktop card | Move window to target Virtual Desktop |
| **Drag & Drop** *(`>= 6px`)* | Card or tile → `+ New desktop` | Create desktop and move window onto it |
| **Hover** *(`>= 3px`)* | Minimap tile | Select and glide The Deep to that window |
| **Click / Drag** | Sounding Line rail | Scrub to nearest depth mark |
| **Vertical / Horizontal Wheel** | Anywhere | Step windows / step Virtual Desktops |
| **Click** | Empty background | Cancel and close |
